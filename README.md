
# Resume_Page

Author: Toby Surtees

This project is a personal resume page for displaying my CV in a more presentable format.
Being my first venture into using Tailwind, I wanted to learn how to build effective UIs in a more maintainable format,
making it easier to update this page in the future. I've done this by applying Tailwind CSS Styles to this page, as well
as using different techniques for displaying information in a compact but readable way.

I then also implemented a simple contact form which uses a form API to help me filter emails and block spam.

Theres plenty of room to improve on this site, and I intend to maintain and improve it over time as I expand my web-dev skill set.

Page Link: [https://mizzmo.github.io/public_resume/](https://mizzmo.github.io/public_resume/)
